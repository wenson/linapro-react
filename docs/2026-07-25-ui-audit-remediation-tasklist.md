## 影响与验证命令

实施时以受影响模块的现有命令为准，并在执行记录中记录实际环境变量和退出码。至少包含：

```bash
pnpm --dir apps/lina-web typecheck
pnpm --dir apps/lina-web exec vitest run <受影响测试文件>
make i18n.check
pnpm --dir hack/tests exec playwright test <受影响宿主用例>
git diff --check
```

插件专属页面的 E2E 必须在插件自己的`hack/tests/e2e/`中执行。`linapro-content-notice`与`linapro-ai-core`的修复不得把插件测试、页面或样式回流到宿主私有目录。若实现引入 API、数据库、缓存、数据权限或开发工具改动，当前清单立即升级版本并读取对应规则后再继续。
