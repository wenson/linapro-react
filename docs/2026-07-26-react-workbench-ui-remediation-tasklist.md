## 影响记录要求

每个阶段都必须在执行记录明确填写：

- `i18n`：本阶段新增或修改的宿主、插件、语言和验证命令；无影响也要写明。
- 缓存一致性：预期无影响；若出现缓存修改，停止并升级 Tasklist。
- 数据权限：预期无影响；移动卡片只能使用原列表可见数据和原权限入口。
- 开发工具跨平台：Vite 和 E2E 清理不得依赖平台专属 Shell 命令。
- E2E 质量审查：本任务改变用户可观察行为，必须触发并检查成功路径、必要失败路径、双语和截图。
- Git：未获得明确授权时，不执行 commit、push、PR、merge、tag 或发布。
