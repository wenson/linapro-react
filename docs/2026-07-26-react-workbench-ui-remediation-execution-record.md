| 标签竖排 | 标签可收缩且会换行 | 标签保持单行、省略和横向滚动，激活标签自动滚入可见区域。 |

| 弹层裁切 | 固定宽度大于手机视口 | 所有受影响`SideSheet`和`Modal`使用首选宽度与视口上限，不覆盖 Semi 内部样式。 |
| 桌面表格遮挡 | 列宽与固定操作列冲突 | 重算列宽、增加省略与滚动，宽表取消会遮挡内容的固定操作列。 |
| 手机列表不可用 | 直接压缩桌面表格 | 核心列表改为同数据、同权限、同操作函数的信息卡。 |
| 通知筛选按钮过宽 | 字段宽度规则误伤按钮 | 字段与操作容器分离，搜索和重置恢复正常尺寸。 |
| AI 档位文案与装饰 | 直接显示种子英文且有无意义圆点 | 按能力类型、方法和档位读取双语说明，缺失时才回退原文，并删除装饰圆点。 |
| 认证页不一致 | 固定最小高度和普通链接 | 四个公开入口统一品牌、语言、宽度和间距，并使用路由链接。 |

| 个人资料等待不清楚 | 只显示小型加载图标 | 增加结构化骨架、延迟说明、错误重试，并保持单次资料请求。 |
