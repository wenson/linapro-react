## ADDED Requirements

### Requirement: 未分类内部错误不得暴露底层实现详情

统一响应边界 SHALL 将无法识别为结构化业务错误或参数校验错误的异常视为内部错误。完整原因必须写入后台诊断日志；调用端只能收到稳定错误编号、运行时翻译键和安全回退文案，不得收到数据库语句、文件系统路径、调用栈、密钥或第三方原始异常详情。

#### Scenario: 数据库查询失败

- **WHEN** 数据库驱动返回包含完整查询语句的错误
- **THEN** 后台诊断日志保留该错误供排查
- **AND** HTTP 响应不包含查询语句、表名或驱动原始错误
- **AND** HTTP 响应包含稳定错误编号和当前语言的安全文案

#### Scenario: 已定义业务错误

- **WHEN** 业务服务返回使用`bizerr`定义的结构化业务错误
- **THEN** 统一响应继续输出该错误的稳定业务错误码、翻译键、参数和本地化消息
- **AND** 不使用内部错误回退覆盖可安全展示的业务语义
