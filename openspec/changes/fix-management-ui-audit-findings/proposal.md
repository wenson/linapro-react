## Why

默认管理工作台在完整 UI 巡检中发现安全错误泄露、手机端失败状态不可见、固定高度压缩内容、宽表操作列离开首屏、接口文档手机端不可用、表单朗读名称错位和部分朗读文案未本地化等问题。这些问题横跨宿主、源码插件和统一响应边界，需要使用同一组验收标准持续跟踪，避免逐页修补后再次回归。

## What Changes

- 收口未分类内部错误：完整原因只进入后台日志，调用端只收到稳定错误编号和安全文案。
- 为桌面表格与手机卡片提供同一套加载、空数据、失败和重试状态，避免响应式样式隐藏失败信息。
- 修复工作台、接口文档和宽表在手机、平板和桌面宽度下的布局。
- 为保留状态的隐藏标签页提供唯一表单控件编号，并完善中英文朗读文案和键盘焦点样式。
- 修复切换查询时旧数据闪现、智能中心按钮被错误拉宽和接口文档中文缺口。
- 增加后端单元测试、前端组件测试和浏览器自动化回归测试。

## Capabilities

### New Capabilities

- `management-ui-quality-baseline`：默认管理工作台及官方源码插件的响应式状态、布局、可访问性和异步切换质量基线。

### Modified Capabilities

- `runtime-message-i18n-governance`：未分类内部错误不得向调用端暴露数据库语句、路径或底层异常详情。

## Impact

- 修改`apps/lina-core`统一响应错误处理和对应单元测试。
- 修改`apps/lina-web`页面、共享状态组件、样式、语言包和宿主浏览器测试。
- 修改命中问题的官方源码插件页面及插件自有测试；插件实现保持在各自目录内。
- 不修改 HTTP 路由、请求或响应 DTO、数据库结构、数据权限、缓存策略和开发工具入口。
